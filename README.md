## 🎨 UI/UXへのこだわり（老若男女にやさしいデザイン）
「NTTドコモのシステム」のような、**「小さな子どもからお年寄りまで、誰でも迷わず操作できるユニバーサルデザイン」**を意識して作成しました。

- **簡単な、ひらがな表記**: 難しい専門用語を減らし、ひらがなや親しみやすい言葉を多く採用しています。
- **視覚的な文字サイズ**: 重要なボタンや次のステップへ進むための案内は、パッと見てすぐにわかるよう文字を大きめに配置しています。
- **直感的なえもじ表現**: ジャンルや設定を絵文字（🏰 ⚔ 🚀 など）でわかりやすく表現し、文字を読まなくても直感的に選べる工夫をしています。

## 🤖 開発の裏側（GitHub Copilot によるバイブコーディング）
このアプリケーションは、最先端のAIペアプログラマーである **GitHub Copilot** との「バイブコーディング（対話しながら直感的にコードを組み上げる手法）」によって作成されました。
AIと密にコラボレーションしながら、アイデアを驚異的なスピードでかたちにする次世代の開発プロセスを取り入れています。

## 🌈 主な機能と特徴
- **多彩なジャンル選択**: ファンタジー、冒険、ミステリー、SF、恋愛、成長、ホラー、歴史、日常、エッセイなど、お好みのジャンルから物語を展開。
- **自由なアイデア追加**: 選んだジャンルに、ユーザー自身のオリジナルの設定やアイデアをプラスしてストーリーを生成可能。
- **直感的なWebデザイン**: ステップ形式でサクサク進められる快適な操作性を実現。

## 🚀 開発者向けローカル実行手順

このプロジェクトをご自身のローカル環境で動かすための手順です。

### 1. リポジトリのクローン
ターミナルを開き、プロジェクトをダウンロードします。
```bash
git clone git@github.com:nanaminlucky/storybloom.git
cd storybloom
```

### 2. 仮想環境の作成と有効化
```bash
# 仮想環境を作成
python -m venv venv

# 仮想環境を有効化 (Mac)
source venv/bin/activate
```

### 3. 依存関係（ライブラリ）のインストール
```bash
pip install -r requirements.txt
```

### 4. 環境変数の設定
プロジェクトのルートディレクトリに `.env` ファイルを作成し、ご自身のOpenAI APIキーを設定してください。
```text
OPENAI_API_KEY=your_openai_api_key_here
```
*(※ GitHub上で公開されている `.env.example` ファイルを参考に設定してください)*

### 5. アプリケーションの起動
```bash
python story_generator.py
```
起動後、ブラウザで `http://127.0.0.1:5000` にアクセスするとローカル環境でアプリが動作します。
